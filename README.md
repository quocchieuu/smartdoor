# 🚪 Smart Door Access Control System

## 📌 Introduction
This is an engineering project designed to build a secure door locking system using a keypad, fingerprint sensor, and STM32 microcontroller.

## 🎥 Demo Video
You can watch the system in action via the link below:
👉 https://drive.google.com/file/d/1cFWxtuJoYx_L34EuLvK9ElIDa3ucEorn/view?usp=sharing

## 🛠 Features
- Fingerprint authentication and password input via keypad.
- Real-time task scheduling using FreeRTOS.
- Low-level peripheral interfacing (UART, SPI, I2C).
